Description:
  A desktop application that allows users to handwrite or upload text images,
  extract the text using Tesseract OCR, translate it into 22+ languages,
  hear pronunciation via gTTS (text-to-speech), and view dictionary definitions
  from multiple free APIs — all in a single Tkinter GUI.

    F. Class: MultilingualRecognitionApp [Lines 85-~775]
       __init__():
         - Window: 1400x800, title "Multilingual Handwriting Recognition"
         - Initializes Translator(), pygame mixer (44100 Hz, 16-bit, stereo)
         - Drawing state: last_x/y, pen/eraser tools, colors, widths
         - Real-time mode state: stroke tracking, process delay (1s)
         - Language map: 22 languages with OCR (Tesseract) and translate
           (Google Translate) codes
         - ThreadPoolExecutor (max 3 workers) for concurrent API calls
         - Audio state tracking and temp directory for audio files

       setup_gui():
         - Left panel: drawing canvas (800x400), language selectors,
           swap-languages button, tool controls (pen/eraser radio),
           real-time toggle checkbox, action buttons (Clear, Upload, Recognize)
         - Right panel:
           - Recognized Text frame (OCR output)
           - Translation frame with output label and "🔊 Listen" button
           - Description frame (pronunciation guide, word definitions)
         - Custom ttk style "Result.TLabel" (Arial 12, #f0f0f0 bg)

       swap_languages():  Swaps source and target language combo boxes
       update_tool():     Updates current_tool from radio button selection
       toggle_realtime(): Toggles real_time_active flag
       process_real_time(): Polls at 100ms intervals; triggers recognition
                            after stroke_delay (0.5s) of inactivity
       start_stroke():    Marks stroke_completed = False, records start coords
       paint():           Draws line segments on canvas (pen or eraser)
       reset_coordinates(): Resets last_x/last_y
       clear_canvas():    Clears canvas and resets all output labels

       upload_image():
         - Opens file dialog (PNG, JPG, JPEG, BMP, GIF, TIFF)
         - Reads image via OpenCV, stores in self.captured_image
         - Calls display_image()

       display_image():
         - Converts BGR to RGB, resizes to 800x400 thumbnail
         - Renders on canvas via ImageTk.PhotoImage

       recognize_text():
         - Screenshots canvas region via ImageGrab (with 10px padding)
         - Converts to OpenCV BGR format
         - Runs enhance_image() pipeline
         - Tesseract config:
           --oem 1 (LSTM engine), --psm 6 (uniform block),
           alphanumeric whitelist, 300 DPI, preserve interword spaces
         - Runs OCR with 5-second timeout
         - If text detected: updates recognized_text_label
         - Translates via googletrans (source -> target language)
         - Fetches pronunciation guide via get_pronunciation_guide()
         - Fetches word definitions (up to 3 words) via get_word_description()
         - Updates description_label with combined results

       stroke_completed():
         - Marks stroke as complete, records timestamp
         - If real-time mode: triggers recognize_text() after delay

       play_pronunciation():
         - Uses gTTS to generate speech MP3 in target language
         - Saves to temp directory with UUID filename
         - Plays via pygame.mixer.music
         - Auto-cleanup via check_audio_finished() polling every 100ms
         - Retry logic (3 attempts) for file save PermissionError

       check_audio_finished():     Polls pygame.mixer.music.get_busy()
       cleanup_audio_file():       Removes a single temp audio file
       cleanup_old_audio_files():  Removes files older than 1 hour
       __del__():                  Cleanup on exit (stop audio, remove temp files)

       get_word_description(word, lang_code):
         - Three-tier API fallback for dictionary definitions:
           1. Free Dictionary API (api.dictionaryapi.dev)
              - Extracts part of speech, definitions, and examples
           2. Wiktionary API (en.wiktionary.org)
              - Parses wikitext for Etymology/Definitions sections
           3. MyMemory Translation API (api.mymemory.translated.net)
              - Returns approximate translations as last resort

       get_pronunciation_guide(text, lang_code):
         - Searches Wiktionary for IPA pronunciation ({{IPA|...}})
         - Falls back to generic message directing user to "Listen" button

    G. main() [Lines ~777-782]
       - Creates Tk root, instantiates MultilingualRecognitionApp, runs mainloop

4. FEATURE LIST
================================================================================

  1. Freehand Drawing Canvas
     - Mouse-driven pen and eraser tools
     - Configurable pen width (3px) and eraser width (50px)
     - Smooth lines with rounded caps

  2. Image Upload
     - Supports PNG, JPG, JPEG, BMP, GIF, TIFF
     - Thumbnail display on canvas (max 800x400)

  3. OCR Text Recognition
     - Tesseract LSTM engine (OEM 1)
     - Adaptive thresholding + morphological preprocessing
     - Alphanumeric whitelist
     - 5-second timeout

  4. Real-Time Recognition Mode
     - Toggle on/off via checkbox
     - Polls at 100ms intervals, triggers after 0.5s stroke inactivity
     - Also checks every 1s during active drawing

  5. Multi-Language Translation (22 languages)
     - Uses googletrans (Google Translate) library
     - Source and target language selectors with swap button
     - Languages: English, Filipino, Cebuano, Spanish, French, German,
       Chinese, Japanese, Italian, Portuguese, Russian, Korean, Arabic,
       Dutch, Greek, Hindi, Turkish, Vietnamese, Thai, Polish,
       Indonesian, Swedish

  6. Text-to-Speech Pronunciation
     - gTTS (Google TTS) engine
     - Generates MP3, plays via pygame mixer
     - Temp file management with auto-cleanup (>1 hour old)
     - Retry logic for file system errors

  7. Dictionary / Word Definitions
     - Multi-API fallback:
       a. Free Dictionary API (definitions, POS, examples)
       b. Wiktionary API (etymology/definitions from wikitext)
       c. MyMemory API (approximate translations)
     - Limited to first 3 words for performance

  8. Pronunciation Guide
     - Extracts IPA notation from Wiktionary when available
     - Falls back to directing user to the Listen button
